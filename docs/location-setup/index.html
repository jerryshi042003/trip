Share your location

Anyone with the family link can see your latest point and when it was sent. You choose when to start and stop.

  1. Install OwnTracks and open it once.
  2. In OwnTracks settings, enable external configuration and confirm.
  3. Open your setup in OwnTracksOpen the private setup link Jerry gives you, then tap Open your setup in OwnTracks. Review and accept the configuration. You can turn external configuration off again after importing.
  4. In iPhone Settings → Apps → OwnTracks → Location, select Always and turn Precise Location on.
  5. Open OwnTracks and publish once with its location button. Check Where for your pin. Leave OwnTracks running so it can send significant moves while the phone is locked.

To stop sending points, set OwnTracks to Manual. The last shared point ages out after 24 hours.

Google Maps backup

In Google Maps, tap your profile picture → Location sharing → New share. Choose a time and use Copy link. Give that link to Jerry to add to Where. Google Maps limits public links to 24 hours.
